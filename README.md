## Features

- **Krea 2 Foundation Model Templates** – Presets for Krea's first image foundation model built from the ground up for complete creative control over style, composition, and aesthetics. Available in three variants: Medium, Medium Turbo, and Large[reference:0][reference:1]
- **Multi-Model Generation Workflows** – Configurations for generating images across Krea's own frontier models plus offerings from Google, OpenAI, Runway, and more — including Krea 1 (most creative model with LoRA support), Flux, Imagen, and Nano Banana[reference:2][reference:3]
- **Real-Time Creative Canvas** – Templates for live generation as you draw, type, or move elements on the Realtime canvas for instant creative feedback and fast iteration[reference:4]
- **Generative Sliders & Style References** – Presets for using Generative Sliders to control aesthetic output while keeping prompts intact, plus style references (Srefs) supporting up to 4 image references per generation[reference:5][reference:6]
- **Nodes & Workflow Automation** – Scripts for automating creative workflows with Krea Nodes — chain over 50 models to generate images, video, audio, and 3D objects in sequence[reference:7][reference:8]
- **Video Generation Across Leading Models** – Templates for generating high-quality videos with Veo, Sora, Wan, Kling, and Krea's own real-time video models[reference:9][reference:10]
- **Enhancer & Upscaling Tools** – Configurations for enhancing and upscaling images up to 22K resolution[reference:11][reference:12]
- **LoRA Fine-Tuning & Custom Style Training** – Workflows for training custom models on specific aesthetics using up to 50 reference images[reference:13][reference:14]
- **AI Character & Moodboard Creation** – Templates for generating character concepts, portraits, full-body designs, and style variants in minutes[reference:15][reference:16]
- **Cross-Platform Compatibility** – Configuration scripts for seamless workflow across Web, iOS, and Android[reference:17]
- **Step-by-step documentation** with visual guides and troubleshooting tips

## Requirements

- **Web:** Modern web browser (Chrome, Firefox, Safari, Edge)
- **Mobile:** iOS or Android device (for mobile access)
- **Internet connection** for AI model access and real-time generation
- **Krea AI account** (Free, Basic, or Pro) – this repository is for legitimate users
- **Basic understanding** of prompt engineering and AI creative concepts

## Usage

1. Download and extract the repository files.
2. Open the `/docs` folder and read the `GettingStarted.md` guide.
3. Choose your desired configuration:
   - **Templates:** Import the prompt and creative workflow templates from `/templates`.
   - **Scripts:** Run the automation scripts from `/scripts` for Node Agent workflows and batch generation.
   - **Presets:** Apply the Krea 2, real-time, and video generation presets from `/presets`.
4. Launch Krea AI and follow the documentation to apply your configurations.
